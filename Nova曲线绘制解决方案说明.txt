# Nova UI 曲线绘制解决方案

## 问题根源
- **LineRenderer** 使用世界坐标系
- **Nova UI** 使用自己的本地布局坐标系
- 两者不兼容，导致曲线无法正确显示

## ✅ 解决方案：使用 Nova UIBlock2D 绘制曲线

### 核心思路
使用多个 `UIBlock2D` 组件作为线段，连接各个点来形成曲线。

### 实现原理
1. 获取各维度分数点的**本地坐标**（不是世界坐标）
2. 在每两个点之间创建一个 `UIBlock2D` 作为线段
3. 计算线段的位置、长度、旋转角度
4. 使用 Nova 的 Length3 设置大小

## 📊 坐标系统说明

### 关键区别
```
【世界坐标】transform.position
- 3D场景中的绝对坐标
- LineRenderer 使用
- 与Nova UI不兼容 ❌

【本地坐标】transform.localPosition  
- 相对于父物体的坐标
- Nova UI 使用
- 曲线绘制应该使用 ✅
```

### Nova UI 坐标特点
1. **相对性**: 所有坐标相对于父UIBlock
2. **布局驱动**: 由Nova的Layout System计算
3. **本地空间**: 始终使用localPosition

## 🎨 UIBlock2D 线段原理

### 一个线段的配置
```csharp
// 起点: (100, 200, 0)
// 终点: (200, 300, 0)

// 1. 计算中点
中点 = (150, 250, 0)

// 2. 计算长度
长度 = √((200-100)² + (300-200)²) = 141.4

// 3. 计算角度
角度 = atan2(300-200, 200-100) = 45°

// 4. 设置UIBlock2D
localPosition = (150, 250, 0)
localRotation = Quaternion.Euler(0, 0, 45)
Size.X = Length.FixedValue(141.4)
Size.Y = Length.FixedValue(2) // 线宽
```

## 🐛 常见问题

### Q1: 看不到曲线
**检查**:
1. Console是否有 "[Nova曲线] 准备绘制 N 条线段"
2. Hierarchy中是否有线段对象
3. 线段的Size是否太小

**解决**:
- 增加曲线宽度到10
- 检查线段对象是否激活
- 检查父物体是否可见

### Q2: 曲线位置错误
**检查**:
1. 点的坐标是否使用本地坐标
2. 父物体的transform是否正确

**解决**:
- 确认使用 `transform.localPosition`
- 检查父物体的localScale（应该是1,1,1）

### Q3: 曲线断裂或错位
**检查**:
1. 点的Z坐标是否一致
2. 是否有点坐标为(0,0,0)

**解决**:
- 统一所有点的Z坐标
- 检查点是否正确显示

### Q4: 线段太多导致性能问题
**优化**:
1. 关闭平滑曲线（减少线段数）
2. 降低平滑度（10 → 5）
3. 使用对象池复用线段
