==================================================
  失语症评定系统使用说明
==================================================

一、功能概述
------------
失语症评定系统基于BDAE（Boston诊断性失语症检查）标准，通过决策树算法自动判断失语症类型。

【评定依据】
系统根据以下4个关键维度的评估分数进行判断：
1. 谈话流利性总分（来自谈话记录）
2. 听辨认图形总分（来自理解记录）
3. 词复述总分（来自复述记录）
4. 句复述总分（来自复述记录）
5. 词命名总分（来自命名记录）


二、失语症类型分类
-----------------

【流畅组】(谈话流利性 ≥ 67)
1. AA - 异常性失语 (Anomic Aphasia)
   - 谈话流利性 ≥ 67
   - 听辨认 ≥ 80
   - 句复述 ≥ 86

2. CA - 传导性失语 (Conduction Aphasia)
   - 谈话流利性 ≥ 67
   - 听辨认 ≥ 80
   - 句复述 < 86

3. TCA - 经皮质感觉性失语 (Transcortical Sensory Aphasia)
   - 谈话流利性 ≥ 67
   - 听辨认 < 80
   - 句复述 ≥ 75

4. WA - 韦尼克失语 (Wernicke's Aphasia)
   - 谈话流利性 ≥ 67
   - 听辨认 < 80
   - 句复述 < 75


【不流畅组】(谈话流利性 < 67)
5. TCM - 经皮质运动性失语 (Transcortical Motor Aphasia)
   - 谈话流利性 < 67
   - 听辨认 ≥ 55
   - 句复述 ≥ 72
   - 词命名 ≥ 80

6. TA/BaA - 完全性失语/混合性经皮质失语 (Total Aphasia/Mixed Transcortical Aphasia)
   - 谈话流利性 < 67
   - 听辨认 ≥ 55
   - 句复述 ≥ 72
   - 词命名 < 80

7. BA - 布洛卡失语 (Broca's Aphasia)
   - 谈话流利性 < 67
   - 听辨认 ≥ 55
   - 句复述 < 72

8. MT - 混合性经皮质失语 (Mixed Transcortical Aphasia)
   - 谈话流利性 < 67
   - 听辨认 < 55
   - 句复述 ≥ 58

9. GA - 全面性失语 (Global Aphasia)
   - 谈话流利性 < 67
   - 听辨认 < 55
   - 句复述 < 58

五、使用方法
-----------

【自动评定】
系统会在显示档案报告时自动计算失语症类型，无需手动操作。

【调用方式】
```csharp
// 方式1：直接计算类型（返回缩写）
string 类型 = 失语症评定工具.计算失语症类型(档案);
// 返回: "AA"、"CA"、"WA"、"BA"等

// 方式2：获取完整名称
string 完整名称 = 失语症评定工具.获取失语症类型全称(类型);
// 返回: "异常性失语 (Anomic Aphasia)"等
```

【必要条件】
要正确评定失语症类型，档案中必须包含以下评估记录：
1. 谈话记录（谈话流利性总分）
2. 理解记录（听辨认图形总分）
3. 复述记录（词复述总分、句复述总分）
4. 命名记录（词命名总分）

如果缺少任何记录，系统将返回"评估数据不完整"。


六、显示位置
-----------

【报告界面】
失语症评定结果显示在档案管理报告界面的"评估结果"区域：
- UI组件：TextBlock 失语症评定
- 显示格式：完整中英文名称
  例如："异常性失语 (Anomic Aphasia)"


七、注意事项
-----------

1. 评估顺序：
   - 必须先完成谈话、理解、复述、命名等量表评估
   - 失语症评定会在显示报告时自动进行

2. 分数依据：
   - 所有判断标准均基于BDAE标准分数阈值
   - 确保各项评估分数准确

3. 数据持久化：
   - 失语症类型会自动保存到档案的"失语症类型"字段中
   - 随档案数据一起保存到本地

4. 调试信息：
   - 系统会在Console输出详细的评定过程日志
   - 便于追踪和验证评定结果


八、扩展说明
-----------

如需修改评定标准或添加新的失语症类型：
1. 修改 失语症评定工具.cs 中的决策树逻辑
2. 在 获取失语症类型全称() 方法中添加新类型的名称映射
3. 更新本说明文档
