【一、功能需求】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

实现选项组的选中提示效果：
✅ 当 IsAnimationOnSelect 为 true 时启用
✅ 选中选项时，该选项组的背景渐显
✅ 切换到其他选项组时，之前选项组的背景渐隐
✅ 同一选项组内切换选项时，背景保持高亮，不闪烁

🎯 核心设计理念：高亮显示"正在操作的选项组"，而非单个选项

❌ 旧版本（v1.0）的问题：
   点击 A1 → A 背景渐显
   点击 A2 → A 背景渐隐 + A 背景渐显 ← 闪烁！❌

✅ 新版本（v2.0）的解决方案：
   点击 A1 → A 背景渐显
   点击 A2 → A 背景保持高亮 ← 无闪烁！✅
   点击 B1 → A 背景渐隐 + B 背景渐显 ← 平滑切换！✅

【三、实现方案】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 新增字段：
   • 背景块：UIBlock2D 引用
   • 渐显时长、渐隐时长：动画时长参数（可调）
   • 选中透明度、未选中透明度：透明度参数（可调）
   • 当前动画：Tweener 引用，避免重复动画
   • 所有选项组：静态列表，管理所有实例（跨组通信的核心）

2. 生命周期管理：
   OnEnable()  → 注册到静态列表
   OnDisable() → 从静态列表移除

3. 核心方法：
   • 播放选中动画()：背景渐显
   • 通知其他选项组取消高亮()：遍历静态列表，通知其他选项组
   • 取消高亮()：背景渐隐（公开方法，供其他选项组调用）
   • 设置背景透明度()：DOTween 动画核心

4. 通信流程：
   用户点击选项 A1
       ↓
   选项组 A.处理选项切换()
       ↓
   ├─→ 播放选中动画() ← A 背景渐显
   └─→ 通知其他选项组取消高亮()
           ↓
           ├─→ 选项组 B.取消高亮() ← B 背景渐隐
           └─→ 选项组 C.取消高亮() ← C 背景渐隐


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【四、使用方法】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Unity Inspector 配置：
1. ✅ 勾选 IsAnimationOnSelect 启用功能
2. ✅ 拖入 UIBlock2D 组件到 背景块 字段
3. ✅ 调整参数（可选）：
   - 渐显时长：默认 0.3 秒
   - 渐隐时长：默认 0.2 秒
   - 选中透明度：默认 1.0（完全不透明）
   - 未选中透明度：默认 0.0（完全透明）

就这么简单！不需要编写任何代码，配置好 Inspector 即可自动工作。
