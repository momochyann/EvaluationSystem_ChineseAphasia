【组件概述】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

选项提示动画_茉 是一个纯动画效果组件，只负责视觉反馈。

功能特点：
✅ 监听一组Toggle的选中事件
✅ 支持NovaUI的Toggle组件
✅ 使用DoTween实现平滑的显影动画
✅ 每个Toggle对应独立的UIBlock2D背景块
✅ 选中一个时显示对应背景，其他背景自动隐藏
✅ 只播放动画，不改变Toggle的选中状态
✅ 不涉及跨组互斥，各组独立工作
✅ 可自定义动画时长、透明度和缓动效果
✅ 接入QFramework架构

步骤1：在Unity中添加组件
------------------------
1. 创建一个空的GameObject，添加 选项提示动画_茉 组件

2. 准备你的选项：
   每个选项需要：
   - Toggle (Nova组件)
   - UIBlock2D (Nova组件，用作背景)


步骤2：配置Inspector参数
------------------------
在 选项提示动画_茉 组件的Inspector中：

【选项组设置】
  ▸ 组名称          - 用于调试日志的组名称
  ▸ 选项列表        - 点击"+"添加选项，然后拖入每个选项的：
      • Toggle      - 该选项的Toggle组件
      • 背景块      - 该选项的UIBlock2D背景块

示例：
  选项列表
    ├─ Element 0
    │   ├─ Toggle: [选项A的Toggle]
    │   └─ 背景块: [选项A的UIBlock2D]
    ├─ Element 1
    │   ├─ Toggle: [选项B的Toggle]
    │   └─ 背景块: [选项B的UIBlock2D]
    └─ Element 2
        ├─ Toggle: [选项C的Toggle]
        └─ 背景块: [选项C的UIBlock2D]

【动画设置】
  ▸ 渐显时长        - 选中时的渐显动画时长（默认0.3秒）
  ▸ 渐隐时长        - 取消选中时的渐隐动画时长（默认0.2秒）
  ▸ 选中透明度      - 选中时的背景透明度（0-1，默认1）
  ▸ 未选中透明度    - 未选中时的背景透明度（0-1，默认0）
  ▸ 渐显缓动        - 渐显动画的缓动效果（默认OutSine）
  ▸ 渐隐缓动        - 渐隐动画的缓动效果（默认InSine）


步骤3：运行游戏
------------------------
✨ 点击组内任意Toggle → 该Toggle的背景渐显，其他背景渐隐
🔄 Toggle的选中状态由你自己的逻辑控制
🎨 本组件只负责背景动画，不会改变Toggle的状态

场景1：一组Toggle选项的高亮管理（推荐）
---------------------------
GameObject结构：
  ├─ 选项组管理器
      └─ 选项提示动画_茉 (组件)
  ├─ Toggle选项A
      ├─ Toggle (组件)
      └─ UIBlock2D (组件，作为背景)
  ├─ Toggle选项B
      ├─ Toggle (组件)
      └─ UIBlock2D (组件，作为背景)
  └─ Toggle选项C
      ├─ Toggle (组件)
      └─ UIBlock2D (组件，作为背景)

配置：
在"选项组管理器"的选项提示动画_茉组件中：
  选项列表:
    Element 0: Toggle = 选项A的Toggle, 背景块 = 选项A的UIBlock2D
    Element 1: Toggle = 选项B的Toggle, 背景块 = 选项B的UIBlock2D
    Element 2: Toggle = 选项C的Toggle, 背景块 = 选项C的UIBlock2D

效果：
  - 用户点击选项A → 选项A的背景渐显，选项B、C的背景渐隐
  - 用户点击选项B → 选项B的背景渐显，选项A、C的背景渐隐
  - Toggle的选中状态由选项组性_茉或其他逻辑控制


场景2：配合选项组性_茉使用
---------------------------
本组件专注于动画效果，可以与选项组性_茉配合使用：
- 选项组性_茉：负责管理Toggle的单选逻辑
- 选项提示动画_茉：负责播放背景高亮动画

示例：
  ├─ 题目1
      ├─ 选项容器
      │   ├─ 选项组性_茉 (管理单选逻辑)
      │   ├─ 选项A、B、C、D (作为子物体)
      └─ 选项提示动画管理器
          └─ 选项提示动画_茉 (管理背景动画)

效果：
  - 选项组性_茉控制只能选中一个Toggle
  - 选项提示动画_茉监听Toggle变化，播放对应背景动画
  - 职责分离，互不干扰

如果需要通过代码控制背景动画：

// 获取组件
var 动画组件 = GetComponent<选项提示动画_茉>();

// 显示指定索引的背景（只播放动画，不改变Toggle状态）
动画组件.显示背景(0);   // 显示第一个选项的背景
动画组件.显示背景(1);   // 显示第二个选项的背景，其他背景自动隐藏

// 隐藏所有背景
动画组件.隐藏所有背景();

// 获取当前高亮的选项索引
int 索引 = 动画组件.获取当前高亮索引();  // 返回-1表示没有高亮

注意：这些API只控制背景的显示/隐藏动画，不会改变Toggle的选中状态

纯动画监听机制：
--------------
本组件只负责监听Toggle的状态变化，播放对应的背景动画。
不会主动改变任何Toggle的选中状态。

流程图：
  用户点击选项A的Toggle（或其他逻辑改变了Toggle状态）
         ↓
  选项A的Toggle.OnToggled事件触发
         ↓
  处理Toggle切换(索引=0, 是否选中=true)
         ↓
  ┌─────────────────────────────────┐
  │ 播放选项B的背景渐隐动画          │
  │ 播放选项C的背景渐隐动画          │
  └─────────────────────────────────┘
         ↓
  播放选项A的背景渐显动画

关键点：
• 组件通过监听Toggle.OnToggled事件来响应状态变化
• 当某个Toggle被选中时，该选项的背景渐显
• 同时，其他所有选项的背景渐隐
• 不会修改任何Toggle的ToggledOn属性
• Toggle的状态管理由选项组性_茉或其他逻辑负责

职责分离：
-------
  选项组性_茉 (或其他逻辑)     选项提示动画_茉
         ↓                           ↓
  管理Toggle单选逻辑          监听Toggle状态变化
         ↓                           ↓
  设置Toggle.ToggledOn         播放背景显隐动画
         ↓                           ↓
    业务逻辑层                    视觉表现层

使用建议：
✅ 单独使用选项组性_茉：
   - Toggle是父子结构，都在一个容器下
   - 所有选项共享一个背景高亮效果
   - 需要管理Toggle的单选逻辑

✅ 单独使用选项提示动画_茉：
   - 已有其他逻辑管理Toggle状态（如选项组性_茉）
   - 只需要为Toggle添加背景动画效果
   - Toggle分散在不同位置
   - 每个选项需要独立的背景高亮效果

✅ 组合使用（推荐）：
   - 选项组性_茉：管理Toggle单选逻辑
   - 选项提示动画_茉：提供视觉反馈
   - 职责清晰，易于维护

【调试技巧】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 查看日志输出
   - 组件初始化时会输出："[组名称] 初始化完成，共 X 个选项"
   - Toggle切换时会输出："[组名称] 选项 X (名称) 被选中/取消选中"
   - 取消高亮时会输出："[组名称] 取消所有高亮"

2. 检查组件引用
   - 如果某个选项的Toggle或背景块为空，会输出警告日志
   - 在Inspector中检查选项列表的引用是否正确
   - 确保每个Element都正确配置了Toggle和背景块

3. 调试动画效果
   - 将渐显/渐隐时长调大（如1秒），方便观察动画过程
   - 在Scene视图中观察UIBlock2D的Color.a值变化
   - 检查选中透明度和未选中透明度的设置

4. 测试组内互斥
   - 依次点击组内不同的Toggle
   - 观察是否只有一个选项高亮
   - 检查日志确认事件是否正确触发

5. 测试跨组互斥
   - 如果启用了"启用跨组互斥"，在场景中添加多个选项提示动画组
   - 依次点击不同组的Toggle
   - 观察是否只有当前组的当前选项高亮

⚠ 配置要求
  - 必须在选项列表中正确配置每个选项的Toggle和背景块
  - Toggle和背景块不能为空，否则该选项会被跳过
  - 建议给组名称设置有意义的名称，方便调试

⚠ 组件销毁
  - OnDisable时会自动停止所有动画，避免内存泄漏
  - 如果启用了跨组互斥，会自动从System注销

⚠ 背景块设置
  - 确保每个UIBlock2D的初始颜色设置正确
  - 初始透明度会在Start时设置为"未选中透明度"
  - 建议在Prefab中设置好UIBlock2D的颜色和形状

⚠ DoTween依赖
  - 项目需要导入DoTween插件
  - 确保DoTween已正确初始化

⚠ Nova UI依赖
  - 需要NovaUI插件
  - 确保Toggle和UIBlock2D组件可用

⚠ 职责范围
  - 本组件只负责背景动画，不管理Toggle的选中状态
  - Toggle的单选/多选逻辑需要由其他组件负责
  - 建议与选项组性_茉配合使用

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 动画不播放？
A: 检查以下几点：
   1. 选项列表中的Toggle和背景块引用是否正确
   2. 渐显/渐隐时长是否大于0
   3. 查看Console是否有错误或警告日志
   4. 确认Toggle被点击时确实触发了OnToggled事件

Q: 背景显示不正确？
A: 确保：
   1. 所有选项都在同一个选项提示动画_茉组件的选项列表中
   2. 每个选项的Toggle和背景块引用正确
   3. 查看日志确认Toggle事件是否被触发

Q: Toggle不能多选了？
A: 注意：
   1. 本组件不控制Toggle的选中状态
   2. Toggle的单选/多选逻辑由选项组性_茉或其他组件控制
   3. 本组件只负责播放背景动画

Q: 动画被打断？
A: 这是正常现象，组件会自动停止之前的动画
   如果希望动画完整播放，可以增加时长或调整缓动效果

Q: 透明度设置不生效？
A: 检查：
   1. 选中透明度和未选中透明度的值（0-1）
   2. 每个UIBlock2D的Color是否正确
   3. 是否有其他脚本也在修改透明度

Q: 如何添加/删除选项？
A: 在Inspector的选项列表中：
   - 点击"+"添加新选项
   - 点击"-"删除选项
   - 拖动调整顺序
   - 记得为每个新选项配置Toggle和背景块

Q: 可以动态添加选项吗？
A: 当前实现在Start时初始化，不支持运行时动态添加
   如需动态添加，需要扩展代码添加相应的API

• QFramework IController接入
