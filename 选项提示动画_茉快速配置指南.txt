【场景示例】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

假设你有一道选择题，需要实现：
- 4个选项：A、B、C、D
- 每个选项有一个Toggle和一个背景块
- 点击某个选项时，该选项的背景高亮显示
- 其他选项的背景自动隐藏
- Toggle的单选逻辑由选项组性_茉管理（或其他逻辑）

【步骤1：准备GameObject结构】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    ├─ 选项A
    │   ├─ Toggle (Nova组件)
    │   └─ UIBlock2D (Nova组件) ← 背景块
    │
    ├─ 选项B

    │   └─ UIBlock2D (Nova组件) ← 背景块
    │
    ├─ 选项C
    │   ├─ Toggle (Nova组件)
    │   └─ UIBlock2D (Nova组件) ← 背景块
    │
    └─ 选项D
        ├─ Toggle (Nova组件)
        └─ UIBlock2D (Nova组件) ← 背景块

【步骤3：配置UIBlock2D背景块】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

为了让动画效果更明显，建议配置背景块：

1. 选中每个选项的UIBlock2D组件

2. 设置背景颜色：
   Color: 例如 RGB(255, 200, 0) 黄色
   Alpha: 1 (透明度会由脚本自动控制)

3. 设置大小和圆角：
   Size: 根据你的Toggle大小调整
   Corner Radius: 10 (圆角效果)

4. 设置位置：
   确保背景块在Toggle的后面（Z轴或渲染顺序）

【拖入操作详解】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如何拖入Toggle和背景块：

方法1：从Hierarchy拖入
  1. 在Hierarchy中找到"选项A"GameObject
  2. 展开它，找到Toggle组件
  3. 将Toggle组件拖入"Element 0"的"Toggle"字段
  4. 将UIBlock2D组件拖入"Element 0"的"背景块"字段

方法2：点击选择
  1. 点击"Element 0"的"Toggle"字段右边的圆点⊙
  2. 在弹出的窗口中选择"选项A"的Toggle组件
  3. 同样方式选择背景块

提示：
  - 可以直接拖入GameObject，Unity会自动找到对应的组件
  - 如果拖入的GameObject没有对应组件，字段会显示为空

【常见错误】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ 错误1：没有配置选项列表
   Console输出：[xxx] 初始化完成，共 0 个选项
   解决：在选项列表中添加选项并配置

❌ 错误2：Toggle或背景块为空
   Console输出：[xxx] 选项 X 的Toggle为空，跳过
   解决：检查选项列表中的引用是否正确拖入

❌ 错误3：动画不显示
   可能原因：
   - 渐显时长为0（改成0.3）
   - 背景块的初始Alpha不是0
   - UIBlock2D被其他物体遮挡

❌ 错误4：点击Toggle没反应
   可能原因：
   - Toggle组件未正确配置
   - Toggle的OnToggled事件被禁用
   - 检查Toggle的Interaction设置

配合选项组性_茉使用（推荐）：
----------------

将业务逻辑和视觉表现分离：

  ├─ 题目1
      ├─ 选项容器
      │   ├─ 选项组性_茉 (管理Toggle单选逻辑)
      │   ├─ 选项A (Toggle + UIBlock2D)
      │   ├─ 选项B (Toggle + UIBlock2D)
      │   ├─ 选项C (Toggle + UIBlock2D)
      │   └─ 选项D (Toggle + UIBlock2D)
      └─ 动画管理器
          └─ 选项提示动画_茉 (管理背景动画)
              配置：将选项A/B/C/D的Toggle和UIBlock2D拖入

效果：
  - 选项组性_茉负责单选逻辑
  - 选项提示动画_茉负责背景动画
  - 职责分离，互不干扰
