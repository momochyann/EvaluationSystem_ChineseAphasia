# 汉语失语症评测系统自动测试使用说明

## 已添加的测试

测试目录：

`Assets/Tests/EditMode/ChineseAphasia`

当前包含：

- `失语症评定工具Tests.cs`
- `BDAE严重程度评定工具Tests.cs`
- `编号规则Tests.cs`
- `档案数据Tests.cs`
- `ChineseAphasia.EditModeTests.asmdef`
- `Assets/Tests/PlayMode/ChineseAphasia/核心业务流程PlayModeTests.cs`
- `Assets/Tests/PlayMode/ChineseAphasia/ChineseAphasia.PlayModeTests.asmdef`

其中 EditMode 测试主要验证纯逻辑和数据结构，不依赖打开具体界面。PlayMode 测试会进入 Unity 播放态测试环境，等待帧更新，适合验证运行时生命周期和轻量业务流程。

## 在 Unity 编辑器里运行

1. 打开 Unity 项目。
2. 点击菜单：`Window > General > Test Runner`。
3. 选择 `EditMode`。
4. 找到 `ChineseAphasia.EditModeTests`。
5. 点击 `Run All`。
6. 查看测试结果，绿色为通过，红色为失败。

## 运行 PlayMode 测试

1. 打开 Unity 项目。
2. 点击菜单：`Window > General > Test Runner`。
3. 选择 `PlayMode`。
4. 找到 `ChineseAphasia.PlayModeTests`。
5. 点击 `Run All`。

当前 PlayMode 测试不会打开真实业务场景，也不会操作真实 UI。它做的是“轻量运行态流程冒烟”：

- 从用户资料创建待测档案。
- 保存理解量表分数、选项和完成状态。
- 根据关键量表数据计算失语症类型和 BDAE 严重程度。
- 创建并销毁一个运行时 `GameObject`，验证 PlayMode 生命周期。

## 命令行运行

Unity 版本为 `2022.3.44f1c1`，可按本机 Unity 安装路径调整命令。

示例：

```powershell
"C:\Program Files\Unity\Hub\Editor\2022.3.44f1c1\Editor\Unity.exe" `
  -batchmode `
  -projectPath "E:\01XiangMu\UnityGit\EvaluationSystem_ChineseAphasia" `
  -runTests `
  -testPlatform EditMode `
  -testResults "E:\01XiangMu\UnityGit\EvaluationSystem_ChineseAphasia\TestResults_EditMode.xml" `
  -quit
```

PlayMode 命令行示例：

```powershell
"C:\Program Files\Unity\Hub\Editor\2022.3.44f1c1\Editor\Unity.exe" `
  -batchmode `
  -projectPath "E:\01XiangMu\UnityGit\EvaluationSystem_ChineseAphasia" `
  -runTests `
  -testPlatform PlayMode `
  -testResults "E:\01XiangMu\UnityGit\EvaluationSystem_ChineseAphasia\TestResults_PlayMode.xml" `
  -quit
```

如果 Unity 安装在中文特供版本路径或其他盘符，请把 `Unity.exe` 路径换成实际路径。

## 当前测试覆盖内容

### 失语症评定

覆盖决策树主要分支：

- AA
- CA
- TCA
- WA
- TCM
- TA或BaA
- BA
- MT
- GA
- 档案为空
- 缺少关键记录
- 类型全称显示文本

### BDAE严重程度

覆盖：

- 0-5级描述文本
- 非法等级返回“未评定”
- 等级选项列表
- 全面性失语低分推荐0级
- 异常性失语高分推荐5级
- 档案为空/记录缺失返回0级

### 编号规则

覆盖：

- 默认编号规则配置
- 前缀编号格式
- 后缀编号格式
- 自定义字符长度1-5位校验

说明：当前编号测试不直接调用 `编号管理界面_茉.生成用户编号()`，因为该方法依赖 QFramework 架构、ES3 本地数据和用户录，直接在 EditMode 中调用可能污染本地业务数据。后续可以单独拆出纯逻辑编号服务后再做更完整的自动测试。

### 档案数据

覆盖：

- 用户基本信息和背景信息字段
- 量表记录初始化
- 评估状态未完成/完成
- 选项选择保存
- 综合评价、指导建议、BDAE等级保存
