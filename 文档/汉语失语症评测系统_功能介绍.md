# 汉语失语症评测系统功能介绍

## 1. 软件概述

汉语失语症评测系统是一套面向失语症语言能力评估、档案留存、报告生成和数据管理的软件。系统围绕“评定人登录、被评估人建档、ABC量表评估、自动汇总评分、失语症类型判断、BDAE严重程度记录、报告打印/下载、备份还原”等流程展开，适用于医院、康复机构或科研场景中的汉语失语症评测工作。

系统提供 PC 端主界面，并保留安卓端/蓝牙同步相关能力。管理员与普通评定人具有不同权限，管理员可进行评定人管理、界面管理、备份还原、编号规则设置等维护操作；评定人主要负责用户信息录入、量表评估、档案查看和报告输出。

## 3. 登录与权限

系统启动后进入登录界面。用户输入账号和密码后，系统会分别检查用户名是否存在、密码是否正确，并在输入框旁显示提示状态。

系统内置默认管理员账号：

| 账号 | 密码 | 说明 |
| --- | --- | --- |
| admin | 123456 | 首次使用或无管理员数据时自动创建。 |

权限分为两类：

| 登录身份 | 可使用功能 |
| --- | --- |
| 管理员 | 首页、评定人管理、用户管理、量表评估、档案管理、界面管理、备份还原、编号管理、个人账号信息修改等。 |

## 5. 评定人管理

评定人管理用于维护可登录系统的评定人员账号。管理员可以新增、编辑、删除评定人信息。

评定人信息包括：

| 字段 | 说明 |
| --- | --- |
| 登录账号 | 评定人登录系统时使用。必填。 |
| 登录密码 | 评定人登录系统时使用。必填。 |
| 姓名 | 评定人姓名。必填。 |
| 性别 | 男/女。 |
| 联系方式 | 电话或其他联系方式。 |
| 身份证号 | 身份识别信息。 |
| 出生日期 | 通过日期选择器选择。 |

保存时系统会校验登录账号、登录密码和姓名是否为空。为空时弹出提示，不会保存。

| 姓名 | 被评估人姓名。必填。 |
| 性别 | 男/女。 |
| 身份证 | 身份信息。 |
| 出生日期 | 通过日期选择器选择。必填。 |
| 民族 | 民族信息。 |
| 监护人 | 监护人姓名。 |
| 关系 | 与被评估人的关系。 |
| 联系方式 | 监护人或本人联系方式。 |
| 居住地址 | 居住地址。 |
| 背景信息 | 发病日期、文化程度、血压、神志状态、家庭成员、烟龄、酒龄、发病前后语言状态、发病时状况、既往病史等。 |

## 8. 量表评估

量表评估是系统核心功能。评定人先从用户列表中选择被评估人，将其加入待测名单，系统会为其创建档案。随后进入量表选择界面，逐项完成评估。

系统当前包含以下评估项目：

| 项目 | 主要记录内容 |
| --- | --- |
| 听/理解 | 是否题、听辨认实物、听辨认图形、口头指令等。 |
| 复述 | 词复述、句复述等。 |
| 说/谈话 | 谈话信息量、谈话流利性、系列语言等。 |
| 出声读/阅读 | 视读、阅读指令、字画匹配、执行指令、填空等。 |
| 执行文字命令 | 阅读相关执行指令能力。 |
| 抄写 | 抄写能力。 |
| 描写/书写 | 写姓名地址、系列书写、听写、看图写字、写病情等。 |
| 听写 | 书写维度中的听写能力。 |
| 计算 | 运算能力。 |
| 命名 | 词命名、颜色识别、颜色命名、反应性命名等。 |
| 结构与空间 | 照画图、摆方块等。 |
| 运用 | 面部动作、上肢动作、复杂动作等。 |
| 利手 | 左利手、右利手或混合利手评定结果。 |

评估界面支持：

- 按题目选择评分项。
- 对图片/材料类题目点击“查看”。
- 提交前检查是否全部完成。
- 返回时询问是否保存当前记录。
- 未全部完成时可保存为“未完成”。
- 再次进入同一档案时自动还原已选内容。
- 所有量表完成后显示“下一步”，进入综合评价和指导建议流程。

## 9. 自动失语症类型评定

系统根据 BDAE 相关指标，通过决策树自动判断失语症类型。报告界面打开时会自动计算并显示结果。

判断依赖以下关键数据：

| 数据来源 | 指标 |
| --- | --- |
| 谈话记录 | 谈话流利性总分。 |
| 理解记录 | 听辨认图形总分。 |
| 复述记录 | 词复述总分、句复述总分。 |
| 命名记录 | 词命名总分。 |

系统可输出的类型包括：

| 缩写 | 类型 |
| --- | --- |
| AA | 异常性失语 Anomic Aphasia |
| CA | 传导性失语 Conduction Aphasia |
| TCA/TCS | 经皮质感觉性失语 Transcortical Sensory Aphasia |
| WA | 韦尼克失语 Wernicke's Aphasia |
| TCM | 经皮质运动性失语 Transcortical Motor Aphasia |
| TA/BaA | 完全性失语/混合性经皮质失语 |
| BA | 布洛卡失语 Broca's Aphasia |
| MT | 混合性经皮质失语 Mixed Transcortical Aphasia |
| GA | 全面性失语 Global Aphasia |

如果核心评估数据不完整，系统会显示“评估数据不完整”。

## 10. BDAE严重程度

报告界面支持选择 BDAE 严重程度等级，范围为 0-5 级。用户确认选择后，系统保存到档案中，并在报告和打印预览中显示对应描述。

| 等级 | 含义简述 |
| --- | --- |
| 0级 | 无有意义的言语或听觉理解能力。 |
| 1级 | 可交流信息范围有限，听者交流困难。 |
| 2级 | 在帮助下可谈熟悉话题，陌生话题困难。 |
| 3级 | 少量帮助或无帮助下可讨论多数日常问题。 |
| 4级 | 言语较流利，但有可观察的理解障碍。 |
| 5级 | 仅有极轻微言语障碍，听者不一定明显察觉。 |

## 11. 档案管理

档案管理用于查看已经创建或已经完成评估的档案。档案数据由用户信息和评估记录组成。

档案内容包括：

| 分类 | 内容 |
| --- | --- |
| 基本信息 | 姓名、性别、出生日期、编号、年龄、评估人员、评估时间。 |
| 个人/家庭信息 | 身份证、联系方式等。 |
| 背景信息 | 发病日期、文化程度、血压、神志状态、家庭成员、烟龄、酒龄、发病前后语言状态、发病时状况、既往病史等。 |
| 量表分数 | 各量表维度的原始分数与汇总分数。 |
| 评估结果 | 利手评定结果、失语症类型、BDAE严重程度。 |
| 综合内容 | 综合评价、指导建议。 |

## 12. 综合评价与指导建议

量表全部完成后，可进入综合评价和指导建议填写/选择界面。系统包含模板设置能力，便于维护常用评价和建议内容。

支持能力：

- 选择综合评价模板。
- 选择指导建议模板。
- 保存评价和建议到当前档案。
- 未保存退出时提示确认。
- 管理员可维护模板内容。

## 13. 报告预览、打印与下载

系统支持生成报告预览，并可选择输出内容：

| 选项 | 说明 |
| --- | --- |
| 量表报告 | 展示基本信息、背景信息、量表分数、评估结果、综合评价与指导建议。 |
| 量表表格 | 展示量表各维度分数的表格/可视化内容。 |
| 两者都选 | 报告和表格同时输出。 |
| 都不选 | 默认输出量表报告。 |

输出方式：

| 方式 | 说明 |
| --- | --- |
| 打印 | 显示打印机选择界面，刷新打印机列表，选择打印机后发送报告。 |
| 下载 | 选择保存位置，导出 Word 文档 `.docx`。 |

打印管理器优先使用 Word 模板生成报告并打印；若模板流程不可用，会回退到截图/HTML打印流程。

## 14. 界面管理

界面管理用于配置软件显示内容和登录背景图，管理员可使用。

可配置内容：

| 项目 | 说明 |
| --- | --- |
| 单位名称 | 用于报告、截图或导出内容中的单位信息。 |
| 软件名称 | 用于登录页、窗口标题等位置。长度过长时会截断。 |
| 登录背景图 | 可选择图片并保存到缓存。 |

## 15. 备份还原与蓝牙同步

备份还原用于保护数据安全，管理员可使用。

备份内容包括：

- 评定人数据。
- 用户数据。
- 档案数据。
- 备份时间。
- 软件版本号。

备份文件为 JSON 格式。还原时会覆盖当前已有数据，请谨慎操作。

蓝牙同步用于按数据类别和日期范围筛选待同步数据，并批量发送至客户端。可同步的数据源包括评定人录、管理员录、用户录和已完成档案录。

## 16. 数据保存

系统数据通过本地存储保存。评定人、用户、档案、软件配置等记录在新增、修改、删除时会自动保存。量表记录在提交或返回时按用户选择保存，保存后再次进入同一档案可还原之前填写内容。

## 17. 使用流程概览

推荐工作流程：

1. 管理员登录系统。
2. 进入评定人管理，创建评定人账号。
3. 进入编号管理，确认用户编号规则。
4. 进入用户管理，录入被评估人资料。
5. 进入量表评估，从用户列表选择被评估人并加入待测。
6. 进入量表选择界面，完成各项评估。
7. 所有量表完成后，填写综合评价和指导建议。
8. 进入档案管理，查看评估报告。
9. 选择 BDAE 严重程度。
10. 根据需要下载或打印报告。
11. 定期使用备份功能导出备份文件。
