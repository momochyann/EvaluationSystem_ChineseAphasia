==================================================
  BDAE严重程度评定系统使用说明
==================================================

一、功能概述
------------
BDAE严重程度评定系统提供了失语症严重程度的6级分类（0-5级），并支持：
1. 根据失语症类型自动推荐严重程度等级
2. 通过下拉框手动选择等级
3. 自动显示对应等级的详细描述文字
4. 数据持久化保存

二、BDAE严重程度等级
-------------------

【0级】
无有意义的言语或听觉理解能力。

【1级】
言语交流中有不连续的言语表达，但大部分需要听者去推测、询问和猜测；
可交流的信息范围有限。听者在言语交流中感到困难。

【2级】
在听者的帮助下，可能进行熟悉话题的交谈。但对陌生话题常常不能表达
出自己的思想，使患者与检查者都感到进行言语交流有困难。

【3级】
在仅需要少量帮助或无帮助下，患者可以讨论几乎所有的日常问题。但由
于言语和（或）理解能力的减弱，使某些谈话出现困难或不大可能。

【4级】
言语流利，但可观察到有理解障碍，但思想和言语表达尚不明显限制。

【5级】
有极少少的可分辨得出的言语障碍，患者主观上感到有点儿困难，但听者
不一定能明显觉察到。


三、等级推荐规则
---------------

系统根据失语症类型和评估分数自动推荐严重程度：

【全面性失语 (GA)】 →  0-2级（最严重）
【布洛卡失语 (BA)】 →  1-3级（严重到中度）
【韦尼克失语 (WA)】 →  1-3级（严重到中度）
【混合性经皮质失语 (MT)】 →  1-2级（严重）
【完全性失语 (TA/BaA)】 →  1-2级（严重）
【经皮质运动性失语 (TCM)】 →  2-4级（中度到轻度）
【经皮质感觉性失语 (TCA/TCS)】 →  2-3级（中度）
【传导性失语 (CA)】 →  3-4级（中度到轻度）
【异常性失语 (AA)】 →  4-5级（最轻微）

五、使用流程
-----------

【自动推荐】
1. 系统计算失语症类型
2. 根据失语症类型和评估分数推荐严重程度等级
3. 自动设置下拉框选中项
4. 显示对应等级的详细描述文字

【手动调整】
1. 用户可以点击下拉框
2. 选择0-5级中的任意等级
3. 系统自动更新描述文字
4. 保存选择到档案中

【数据保存】
- 等级自动保存到 档案.BDAE严重程度等级
- 下次打开报告时自动还原保存的等级


六、智能推荐逻辑
---------------

系统综合考虑以下因素：
1. 失语症类型（主要因素）
2. 谈话流利性分数
3. 理解能力平均分（听辨认 + 口头指令）
4. 表达能力平均分（流利性 + 信息量）

推荐算法：
- 先根据失语症类型确定大致范围
- 再根据具体评估分数在范围内细化
- 采用专业的临床经验阈值


七、使用示例
-----------

```csharp
// 返回: ["0级", "1级", "2级", "3级", "4级", "5级"]
```


八、注意事项
-----------

1. 推荐等级仅供参考：
   - 系统推荐基于统计规律和专业经验
   - 最终诊断需要专业人员结合临床实际确定
   - 可通过下拉框手动调整

2. 数据依赖：
   - 需要完整的谈话、理解等评估记录
   - 依赖失语症类型评定结果
   - 确保评估数据准确性

3. UI集成：
   - 下拉框使用Nova UI的Dropdown组件
   - 下拉框选项在Start()时初始化
   - 选择变化时自动更新TextBlock显示

4. 数据持久化：
   - 等级保存在档案的BDAE严重程度等级字段
   - 与档案一起序列化保存
   - 支持数据还原和修改


九、扩展说明
-----------

如需修改推荐逻辑：
1. 修改 BDAE严重程度评定工具.cs 中的推荐方法
2. 调整各失语症类型的等级判断阈值
3. 更新本使用说明文档

如需添加新的描述文字：
1. 修改 获取严重程度描述() 方法
2. 保持等级范围在0-5
