【选项组性_茉 选中提示功能使用说明】

═══════════════════════════════════════════════════════════════════

一、功能概述
═══════════════════════════════════════════════════════════════════
为选项组添加了选中提示动画效果，用于提示"当前正在操作哪个选项组"：

• 当某个选项组中的任意选项被选中时 → 该选项组的背景渐显（高亮）
• 当切换到其他选项组时 → 之前选项组的背景自动渐隐
• 在同一个选项组内切换选项 → 背景保持高亮状态，不会闪烁

🎯 核心设计理念：高亮显示"正在操作的选项组"，而非单个选项

二、使用步骤
═══════════════════════════════════════════════════════════════════

1. 在 Unity Inspector 中设置：
   
   ✓ IsAnimationOnSelect：勾选此项以启用动画效果
   
   ✓ 背景块：拖入需要显示选中效果的 UIBlock2D 组件
     （通常是挂载脚本的 GameObject 上的 UIBlock2D 组件）
   
   ✓ 渐显时长：选中时的渐显动画时长（默认 0.3 秒）
   
   ✓ 渐隐时长：取消选中时的渐隐动画时长（默认 0.2 秒）
   
   ✓ 选中透明度：选中时的目标透明度（默认 1.0，完全不透明）
   
   ✓ 未选中透明度：未选中时的目标透明度（默认 0.0，完全透明）

2. 在场景中配置：
   
   • 确保 GameObject 上有 UIBlock2D 组件
   • 将该 UIBlock2D 组件拖到"背景块"字段
   • 设置 UIBlock2D 的颜色（RGB 值），透明度会由脚本自动控制

三、工作原理
═══════════════════════════════════════════════════════════════════

💡 跨选项组通信机制：

• 静态列表管理：
  - 所有启用的选项组实例都注册到静态列表中
  - OnEnable 时自动注册，OnDisable 时自动移除

• 选中流程：
  1. 用户点击选项组 A 的某个选项
  2. 选项组 A 的背景渐显（高亮）
  3. 选项组 A 通知其他所有选项组（B、C、D...）
  4. 其他选项组自动渐隐背景

• 同组切换：
  - 在同一选项组内切换不同选项时
  - 背景保持高亮状态，不会重复播放动画
  - 提供流畅的用户体验

• 动画细节：
  - 使用 DOTween 的 OutQuad 缓动曲线
  - 自动停止之前的动画，避免冲突
  - 只修改透明度（Alpha），不改变 RGB 颜色值

四、性能说明
═══════════════════════════════════════════════════════════════════

✓ DOTween 是高性能的动画库，性能消耗极低
✓ 只在选项切换时触发动画，不会持续消耗性能
✓ 使用 Tweener 引用避免内存泄漏和重复动画
✓ 相比其他方案（如 Animator、协程），DOTween 是最优选择

六、常见问题
═══════════════════════════════════════════════════════════════════

Q: 动画不生效？
A: 检查以下几点：
   1. IsAnimationOnSelect 是否勾选
   2. 背景块字段是否已赋值
   3. UIBlock2D 组件是否存在

Q: 想要更快/更慢的动画？
A: 调整"渐显时长"和"渐隐时长"参数即可

Q: 想要半透明效果？
A: 调整"选中透明度"为 0.5-0.8 之间的值

Q: 多个选项组如何实现互斥高亮？
A: 自动实现！通过静态列表管理，当选项组 A 被选中时，
   会自动通知所有其他选项组（B、C、D...）取消高亮。
   不需要手动配置任何引用或连接。

Q: 在同一选项组内切换选项，背景会闪烁吗？
A: 不会！这正是新设计的优点。在同一选项组内切换选项时，
   背景会保持高亮状态，不会触发渐隐再渐显的动画。

Q: 多个场景或界面可以同时使用吗？
A: 可以！静态列表会在 OnEnable/OnDisable 时自动管理，
   支持多场景、动态加载和销毁的情况。

七、代码结构
═══════════════════════════════════════════════════════════════════

新增字段：
• 背景块：UIBlock2D 引用
• 渐显时长、渐隐时长：动画时长参数
• 选中透明度、未选中透明度：透明度参数
• 当前动画：Tweener 引用，用于控制动画
• 所有选项组：静态列表，管理所有实例（跨选项组通信的核心）

新增方法：
• OnEnable()：注册到静态列表
• OnDisable()：从静态列表移除
• 播放选中动画()：选中时调用
• 通知其他选项组取消高亮()：跨组通信的核心方法
• 取消高亮()：公开方法，供其他选项组调用
• 设置背景透明度()：核心动画方法

修改位置：
• Start()：添加初始化逻辑
• 处理选项切换()：添加动画触发和跨组通知逻辑

八、效果演示（文字描述）
═══════════════════════════════════════════════════════════════════

场景：有三个选项组 A、B、C

1. 初始状态：
   A 背景透明 ○
   B 背景透明 ○
   C 背景透明 ○

2. 点击选项组 A 的选项1：
   A 背景渐显 ● (0.3秒动画)
   B 背景透明 ○
   C 背景透明 ○

3. 在选项组 A 内切换到选项2：
   A 背景保持 ● (无动画，背景不闪烁)
   B 背景透明 ○
   C 背景透明 ○

4. 点击选项组 B 的选项1：
   A 背景渐隐 ○ (0.2秒动画)
   B 背景渐显 ● (0.3秒动画)
   C 背景透明 ○

5. 点击选项组 C 的选项1：
   A 背景透明 ○
   B 背景渐隐 ○ (0.2秒动画)
   C 背景渐显 ● (0.3秒动画)
