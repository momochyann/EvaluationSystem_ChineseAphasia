==================================================
  评估模板系统使用说明
==================================================

一、功能概述
------------
为档案录系统添加了"综合评价"和"指导建议"两个字段，支持使用模板快速填写内容。

【主要功能】
✓ 创建和管理评价模板和建议模板
✓ 选择已有模板快速填充内容
✓ 修改现有模板内容
✓ 手动编辑评价和建议内容


二、数据结构变更
----------------

【档案类新增字段】(档案录.cs)
public class 档案 : I记贞
{
    // ... 原有字段 ...
    public string 综合评价 = "";
    public string 指导建议 = "";
}

【新增模型】(评估模板录.cs)
- 评估模板类型：综合评价、指导建议
- 评估模板数据类：模板名称、内容、类型、时间等
- 综合评价模板录
- 指导建议模板录


三、UI组件配置
--------------

【1. 评估模板选择界面】(主界面)
文件：[2]评估模板选择界面.cs

需要配置的SerializeField：
- 综合评价输入框：TextField (Nova UI)
- 综合评价模板按钮：Button (Nova UI)
- 指导建议输入框：TextField (Nova UI)
- 指导建议模板按钮：Button (Nova UI)
- 保存按钮：Button (Nova UI)
- 返回按钮：Button (Nova UI)
- 模板设置界面：评估模板设置显示组件引用

【2. 评估模板设置显示界面】(弹出界面)
文件：[3]评估模板设置显示.cs

需要配置的SerializeField：
- 新模板内容输入：TextField (Nova UI，可选，用于快速输入初始内容)
- 添加模板按钮：Button (Nova UI)
- 关闭按钮：Button (Nova UI)
- 模板列表容器：Transform (ScrollView Content)
- 模板条目预制体：GameObject

【3. 模板条目显示】(预制体组件)
文件：[4]模板条目显示.cs

需要配置的SerializeField：
- 模板名称文本：TextField (Nova UI，可直接编辑)
- 模板内容文本：TextField (Nova UI，可直接编辑)
- 保存按钮：Button (Nova UI)
- 选择按钮：Button (Nova UI)


四、Unity场景配置步骤
---------------------

步骤1：创建评估模板选择界面
├─ 创建GameObject，添加"评估模板选择界面"脚本
├─ 创建综合评价区域（标签+输入框+按钮）
├─ 创建指导建议区域（标签+输入框+按钮）
└─ 创建操作按钮（保存、返回）

步骤2：创建评估模板设置显示界面
├─ 创建GameObject，添加"评估模板设置显示"脚本
├─ 默认设置为隐藏状态（SetActive(false)）
├─ 创建添加模板区域（可选内容输入框、添加按钮）
└─ 创建模板列表区域（ScrollView + Content）

步骤3：创建模板条目预制体
├─ 创建GameObject，添加"模板条目显示"脚本
├─ 创建编辑区域（名称TextField、内容TextField - 可直接编辑）
├─ 创建按钮区域（保存按钮、选择按钮）
└─ 保存为预制体

步骤4：连接组件引用
├─ 在评估模板选择界面中拖拽UI组件到对应字段
├─ 将模板设置界面GameObject拖到"模板设置界面"字段
├─ 在模板设置界面中拖拽模板条目预制体
└─ 在模板条目预制体中拖拽UI组件


五、使用流程
------------

【添加模板】
1. 点击"添加模板"按钮
2. 自动生成一个空模板（默认名称"新模板"）
3. 新模板出现在列表中
4. 直接在模板条目中编辑名称和内容

【编辑模板】
1. 在模板条目中，直接点击名称或内容输入框
2. 输入或修改文本
3. 点击"保存"按钮保存修改
4. 修改自动保存到数据库

【使用模板】
1. 点击"选择模板"按钮
2. 在模板列表中点击某个模板的"选择"按钮
3. 模板内容自动填充到主界面输入框
4. 可以继续手动编辑

【保存到档案】
1. 填写完综合评价和指导建议内容
2. 点击"保存"按钮
3. 弹出保存确认对话框
4. 确认后保存到当前档案
5. 显示"保存成功"提示
6. 自动返回上一界面

【返回/取消】
1. 点击"返回"按钮
2. 如果有未保存的内容，弹出退出确认对话框
3. 确认后返回上一界面
4. 如果没有修改，直接返回


六、默认模板
------------

系统首次运行时会自动创建两个默认模板：

【综合评价默认模板】
模板名称：默认综合评价模板
模板内容：患者表现良好，各项评估指标正常。

【指导建议默认模板】
模板名称：默认指导建议模板
模板内容：建议患者继续保持良好的康复训练习惯，定期复查。


七、技术实现
------------

【数据持久化】
使用QFramework的StorageUtility自动保存到本地

【命令模式】
- 增记于录：添加新模板
- 改记于录：修改模板或保存档案
- 删记于录：删除模板(可扩展)

【架构注册】(HotFixTemplateArchitecture.cs)
RegisterModel<综合评价模板录>(new 综合评价模板录());
RegisterModel<指导建议模板录>(new 指导建议模板录());

【异步提示系统】
使用UniTask和告示预制体实现异步对话框：
- 显示提示()：显示信息提示框
- 显示确认()：显示确认对话框，返回bool值
- 告示_茉.等待确认显示()：等待用户操作


八、用户体验优化
---------------

【保存提示】
- 保存前显示确认对话框
- 保存成功后显示成功提示
- 保存失败时显示错误提示

【退出提示】
- 检测是否有未保存的内容
- 有修改时显示退出确认对话框
- 防止误操作导致数据丢失

【告示预制体】
使用项目现有的"告示"预制体：
- 通过YooAssetPfbPoolUtility加载
- 显示在界面管理器的transform下
- 自动销毁，不影响性能

十、注意事项
------------

1. 【重要】使用Nova UI组件：
   - 文本显示和输入都使用 TextField（不是TextBlock或TMP_InputField）
   - 按钮使用 Nova Button
2. TextField属性访问使用 .Text（大写T），不是 .text
3. 模板条目中的名称和内容都是可编辑的TextField
4. 点击"添加模板"直接生成空模板，无需预先输入名称
5. 模板内容直接在条目中编辑，点击"保存"按钮保存
6. 选择模板时会自动保存当前编辑内容
7. 输入框建议使用多行模式，设置合理的字符数限制
8. 模板设置界面初始状态必须隐藏
9. 确保所有组件引用都已正确配置


十一、故障排查
------------

【问题：模板不显示】
原因：容器或预制体未配置
解决：检查Inspector中的引用

【问题：保存失败】
原因：档案录未初始化
解决：检查架构注册是否正确

【问题：界面不弹出】
原因：模板设置界面引用错误
解决：重新拖拽组件引用

【问题：编译错误】
原因：Unity还没有重新编译脚本
解决：重启Unity编辑器，让其重新编译所有脚本
