假设有 3 个选项组：

┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│  选项组 A       │  │  选项组 B       │  │  选项组 C       │
├─────────────────┤  ├─────────────────┤  ├─────────────────┤
│ ○ 选项 A1       │  │ ○ 选项 B1       │  │ ○ 选项 C1       │
│ ○ 选项 A2       │  │ ○ 选项 B2       │  │ ○ 选项 C2       │
│ ○ 选项 A3       │  │ ○ 选项 B3       │  │ ○ 选项 C3       │
└─────────────────┘  └─────────────────┘  └─────────────────┘


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【操作序列 1：点击选项组 A 的选项 A1】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

用户操作：
    👆 点击 [选项 A1]
         ↓

选项组 A 内部处理：
    1. 处理选项切换(A1, true)
    2. 设置 当前选中选项 = A1
    3. 播放选中动画() ← 背景渐显
    4. 通知其他选项组取消高亮()
         ↓
         ├──→ 选项组 B.取消高亮() ← 背景渐隐
         └──→ 选项组 C.取消高亮() ← 背景渐隐

视觉效果：
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│▓▓选项组 A ▓▓▓▓▓│  │  选项组 B       │  │  选项组 C       │
├─────────────────┤  ├─────────────────┤  ├─────────────────┤
│ ● 选项 A1       │  │ ○ 选项 B1       │  │ ○ 选项 C1       │
│ ○ 选项 A2       │  │ ○ 选项 B2       │  │ ○ 选项 C2       │
│ ○ 选项 A3       │  │ ○ 选项 B3       │  │ ○ 选项 C3       │
└─────────────────┘  └─────────────────┘  └─────────────────┘
  ↑ 背景高亮 ✨


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【操作序列 2：在选项组 A 内切换到选项 A2】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

用户操作：
    👆 点击 [选项 A2]
         ↓

选项组 A 内部处理：
    1. 处理选项切换(A1, false) ← A1 被自动取消
       ⚠️ 注意：这里不播放渐隐动画！
    2. 处理选项切换(A2, true)
    3. 设置 当前选中选项 = A2
    4. 播放选中动画() ← 背景已经是显示状态，直接设置透明度 = 1
    5. 通知其他选项组取消高亮() ← B 和 C 本来就是隐藏的，无影响

关键点：
    ✓ 背景保持高亮状态，无闪烁！
    ✓ 因为背景透明度已经是 1.0，动画实际上不会有视觉变化
    ✓ 用户感觉：选项组 A 一直处于"操作中"状态

视觉效果：

│▓▓选项组 A ▓▓▓▓▓│  │  选项组 B       │  │  选项组 C       │
├─────────────────┤  ├─────────────────┤  ├─────────────────┤
│ ○ 选项 A1       │  │ ○ 选项 B1       │  │ ○ 选项 C1       │
│ ● 选项 A2       │  │ ○ 选项 B2       │  │ ○ 选项 C2       │
│ ○ 选项 A3       │  │ ○ 选项 B3       │  │ ○ 选项 C3       │
└─────────────────┘  └─────────────────┘  └─────────────────┘
  ↑ 背景依然高亮 ✨（无闪烁）

【操作序列 3：切换到选项组 B 的选项 B1】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

用户操作：
    👆 点击 [选项 B1]
         ↓

选项组 B 内部处理：
    1. 处理选项切换(B1, true)
    2. 设置 当前选中选项 = B1
    3. 播放选中动画() ← 背景渐显（0.3秒）
    4. 通知其他选项组取消高亮()
         ↓
         ├──→ 选项组 A.取消高亮() ← 背景渐隐（0.2秒）✨
         └──→ 选项组 C.取消高亮() ← 背景本来就隐藏，无变化

并行发生（由于选项组 A 收到通知）：
    选项组 A 的背景开始渐隐动画

【静态列表管理机制】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

所有选项组实例注册到一个静态列表中：

    ┌───────────────────────────────────────┐
    │   static List<选项组性_茉> 所有选项组   │
    ├───────────────────────────────────────┤
    │ [0] → 选项组 A 实例                    │
    │ [1] → 选项组 B 实例                    │
    │ [2] → 选项组 C 实例                    │
    │ ...                                   │
    └───────────────────────────────────────┘

生命周期管理：
    
    OnEnable()  → 添加到列表
    OnDisable() → 从列表移除
    
    ✓ 支持动态加载/卸载
    ✓ 支持多场景
    ✓ 自动清理，无内存泄漏

【关键设计要点】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ✅ 同组内切换不闪烁
   - 背景保持高亮状态
   - 只更新选中的选项，不重播动画

2. ✅ 跨组切换平滑
   - 新选项组：渐显（0.3秒）
   - 旧选项组：渐隐（0.2秒）
   - 两个动画同时播放，视觉流畅

3. ✅ 自动管理，无需配置
   - 通过静态列表自动发现所有选项组
   - 无需手动设置引用或连接

4. ✅ 性能优化
   - 使用 Tweener 引用避免重复动画
   - DOTween 高性能动画库
   - 只修改透明度，不改变颜色

5. ✅ 生命周期安全
   - OnEnable/OnDisable 自动管理
   - 支持动态加载/卸载
   - 无内存泄漏
