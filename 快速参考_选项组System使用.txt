Architecture (HotFixTemplateArchitecture)
    ↓
System (选项组高亮管理System) ← 我们在这里
    ↓

为什么使用 System？
✅ 集中管理状态
✅ 解耦组件之间的依赖
✅ 易于测试和扩展
✅ 符合 QFramework 架构规范

1. 选项组启用
   OnEnable() → System.注册选项组()

2. 用户点击选项
   选项切换 → 播放动画 → System.设置高亮组()

3. System 处理
   取消其他组高亮 → 更新当前高亮组

4. 选项组禁用
   OnDisable() → System.注销选项组()

Q: 如何在其他脚本中使用？
A: 确保脚本实现了 IController 接口：
   public class 你的脚本 : MonoBehaviour, IController
   {
       public IArchitecture GetArchitecture()
       {
           return HotFixTemplateArchitecture.Interface;
       }
   }
   然后就可以使用：this.GetSystem<选项组高亮管理System>()

Q: 多个场景有多个选项组怎么办？
A: 没问题！System 会自动管理所有场景的选项组
   每个场景的选项组会在 OnEnable 时注册
   切换场景时会自动注销

Q: 性能如何？
A: 非常好！
   - 注册/注销：O(1) 时间复杂度
   - 设置高亮：O(n)，n = 选项组数量（通常很少）
   - 无额外内存开销

Q: 可以禁用某个选项组的高亮吗？
A: 取消勾选 IsAnimationOnSelect 即可
   该选项组将不参与高亮管理
