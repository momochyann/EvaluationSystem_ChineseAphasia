==================================================
  量表书写栏使用说明
==================================================

一、功能概述
------------
量表书写栏_茉 继承自 量表评估基类_茉，用于评估书写能力。

【6个评估维度】
1. 写姓名地址 - 表分择性评估
2. 抄写 - 表分择性评估
3. 系列书写 - 表分择性评估
4. 听写 - 表分择性评估
5. 看图写字 - 表分择性评估
6. 写病情 - 直接输入分数（0-5分）

【特殊说明】
- 前5个维度使用"表分择性_茉"组件，通过栏目组统一管理
- "写病情"维度是直接输入0-5分，不使用表分择性


二、数据结构
------------

【书写记录类】(档案录.cs)

```csharp
public class 书写记录 : 档案记录接口
{
    public string 评估时间 { get; set; }
    public 评估状态 是否完成 { get; set; }
    
    // 六个维度的分数
    public int 写姓名地址总分;
    public int 抄写总分;
    public int 系列书写总分;
    public int 听写总分;
    public int 看图写字总分;
    public int 写病情分数; // 直接输入0-5分
    
    // 存储选项组名称和选中索引的映射（表分择性使用）
    public Dictionary<string, int> 选项组选择 = new Dictionary<string, int>();
}
```

四、写病情输入框配置
--------------------

【方式一：使用TextBlock（推荐）】

1. 创建一个TextBlock用于显示和输入分数
2. 在Inspector中将其拖入"写病情输入框"字段
3. 可以通过代码调用方法来设置分数

【方式二：使用InputField】

如果需要用户直接输入，可以：
1. 创建一个InputField
2. 监听InputField的OnValueChanged事件
3. 调用 从文本设置写病情分数(string) 方法

示例代码：
```csharp
// 在其他脚本中
量表书写栏_茉 书写栏 = FindObjectOfType<量表书写栏_茉>();
inputField.onValueChanged.AddListener(书写栏.从文本设置写病情分数);
```

【方式三：使用按钮】

创建6个按钮（0-5分），每个按钮点击时调用：
```csharp
书写栏.设置写病情分数(分数);
```


五、公共方法
------------

【1. 设置写病情分数】
```csharp
public void 设置写病情分数(int 分数)
```
- 参数：分数（0-5）
- 功能：设置写病情的分数
- 示例：书写栏.设置写病情分数(3);

【2. 从文本设置写病情分数】
```csharp
public void 从文本设置写病情分数(string 分数文本)
```
- 参数：分数文本（"0"-"5"）
- 功能：从字符串解析并设置分数
- 示例：书写栏.从文本设置写病情分数("4");

【3. 获取写病情分数】
```csharp
public int 获取写病情分数()
```
- 返回：当前写病情分数（0-5）
- 功能：获取当前设置的分数
- 示例：int 分数 = 书写栏.获取写病情分数();


六、工作流程
------------

【评估流程】

1. 用户进入书写评估界面
2. 系统自动还原之前保存的数据（如果有）
3. 用户完成5个表分择性评估
4. 用户输入或选择写病情分数（0-5分）
5. 点击"提交"按钮
6. 系统检查是否全部完成
7. 保存数据并返回

【数据保存】

保存时会记录：
- 5个维度的表分择性总分
- 写病情的直接分数
- 所有表分择性的详细选择（用于还原）
- 评估时间和完成状态

【数据还原】

重新打开界面时：
- 自动还原5个维度的表分择性选择
- 自动还原写病情分数
- 显示在对应的UI组件上


七、完成条件检查
----------------

【检查逻辑】

提交时会检查两个条件：

1. 所有栏目组（表分择性）是否全部完成
   - 每个栏目组内的所有表分择性都必须选择

2. 写病情分数是否有效
   - 必须在0-5分范围内
   - 默认值0也是有效的

【提示信息】

- 如果表分择性未完成："请完成所有表分择性评估项"
- 如果写病情分数无效："请输入写病情分数（0-5分）"
- 其他情况："请完成全部书写评估后保存"

九、使用示例
------------

【示例1：使用按钮设置写病情分数】

在Unity中创建6个按钮（0-5分），每个按钮的OnClick事件：

```csharp
// 按钮0的点击事件
public void 点击分数0()
{
    FindObjectOfType<量表书写栏_茉>().设置写病情分数(0);
}

// 按钮1的点击事件
public void 点击分数1()
{
    FindObjectOfType<量表书写栏_茉>().设置写病情分数(1);
}

// ... 依此类推到5
```

【示例2：使用Slider设置分数】

```csharp
public class 写病情分数控制器 : MonoBehaviour
{
    [SerializeField] Slider 分数滑块;
    [SerializeField] 量表书写栏_茉 书写栏;
    
    void Start()
    {
        分数滑块.minValue = 0;
        分数滑块.maxValue = 5;
        分数滑块.wholeNumbers = true;
        分数滑块.onValueChanged.AddListener(OnSliderChanged);
    }
    
    void OnSliderChanged(float value)
    {
        书写栏.设置写病情分数((int)value);
    }
}
```

【示例3：使用Dropdown设置分数】

```csharp
public class 写病情下拉控制器 : MonoBehaviour
{
    [SerializeField] Dropdown 分数下拉框;
    [SerializeField] 量表书写栏_茉 书写栏;
    
    void Start()
    {
        // 添加选项 0-5
        分数下拉框.options.Clear();
        for (int i = 0; i <= 5; i++)
        {
            分数下拉框.options.Add(new Dropdown.OptionData(i.ToString()));
        }
        
        分数下拉框.onValueChanged.AddListener(OnDropdownChanged);
    }
    
    void OnDropdownChanged(int index)
    {
        书写栏.设置写病情分数(index);
    }
}
```


十、常见问题
------------

Q1: 为什么写病情不使用表分择性？
A: 写病情是直接评分（0-5分），不需要复杂的表格选择，直接输入更简单。

Q2: 写病情分数默认值是多少？
A: 默认是0分，这也是一个有效值。

Q3: 可以不输入写病情分数吗？
A: 不可以，写病情分数是必填项，但0分是有效的。

Q4: 如果输入超出0-5范围的分数会怎样？
A: 会被拒绝并输出警告日志，不会保存。

Q5: 写病情输入框可以不配置吗？
A: 可以不配置TextBlock，但必须通过代码调用方法设置分数。

Q6: 栏目组的维度名称必须完全一致吗？
A: 是的，switch语句是精确匹配的，必须使用指定的名称。

Q7: 可以添加更多维度吗？
A: 可以，在书写记录类中添加字段，在保存额外数据方法中添加case分支即可。

Q8: 表分择性如何配置？
A: 每个栏目组下添加表分择性_茉组件，参考"栏目组配置说明.txt"。
