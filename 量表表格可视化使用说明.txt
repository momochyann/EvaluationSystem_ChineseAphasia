# 量表表格可视化_茉 使用说明

## 功能概述
该组件用于在打印报告界面中实现量表表格的可视化显示，根据各维度的分数显示对应的点，并用平滑曲线连接这些点。

## 核心功能

### 1. 分数点显示逻辑
- **输入**: 维度分数（0-100分）
- **处理**: 取分数的十位数（例如：36分 → 3）
- **显示**: 从后往前数第（10-十位数）个子物体
- **示例**: 
  - 36分 → 十位数=3 → 显示倒数第7个点（10-3=7）
  - 85分 → 十位数=8 → 显示倒数第2个点（10-8=2）
  - 100分 → 十位数=10 → 显示倒数第0个点（最后一个）

### 2. 曲线绘制
- 使用 `LineRenderer` 组件绘制连接线
- 支持两种模式：
  1. **直线模式**: 直接连接各点
  2. **平滑曲线模式**: 使用 Catmull-Rom 样条插值生成平滑曲线

## 组件配置

### Inspector 面板配置

#### 维度配置（维度列表）
每个维度需要配置：
- **维度名称**: 用于匹配分数数据的键（例如："谈话流利性"）
- **分数点容器**: 包含所有分数点（0-100分）的父物体 Transform
- **当前分数**: 该维度的分数值（自动从档案数据填充）

#### 曲线配置
- **曲线渲染器**: LineRenderer 组件（可自动创建）
- **曲线颜色**: 曲线的颜色
- **曲线宽度**: 曲线的线宽
- **使用平滑曲线**: 是否使用平滑插值
- **平滑度**: 每段的插值点数量（平滑曲线模式下有效）

## Unity 场景设置步骤

### 1. 准备分数点容器
在量表表格界面中，为每个维度创建点容器：
```
量表表格界面
  └─ 流利性容器
      ├─ 100分点
      ├─ 90分点
      ├─ 80分点
      ├─ 70分点
      ├─ 60分点
      ├─ 50分点
      ├─ 40分点
      ├─ 30分点
      ├─ 20分点
      ├─ 10分点
      └─ 0分点
```

### 2. 添加可视化组件
1. 在 `量表表格界面` 下创建一个空物体命名为 "量表表格可视化"
2. 添加 `量表表格可视化_茉` 组件
3. 配置维度列表：
   - 添加所需数量的维度
   - 为每个维度设置名称和分数点容器

### 3. 在打印报告界面中关联
在 `打印报告界面_茉` 的 Inspector 中：
1. 找到"界面容器"分组
2. 将量表表格可视化组件拖拽到"量表表格可视化"字段

## 代码使用示例

### 自动更新（已集成）
打印报告界面会自动调用可视化更新：
```csharp
// 在 显示档案详情 中自动调用
if (显示量表表格 && 量表表格可视化 != null)
{
    更新量表表格可视化(当前显示档案);
}
```

### 手动设置分数
```csharp
// 设置所有维度的分数
Dictionary<string, int> 分数 = new Dictionary<string, int>
{
    { "谈话流利性", 36 },
    { "谈话信息量", 85 },
    { "系列语言", 50 }
};
量表表格可视化.设置分数(分数);

// 设置单个维度
量表表格可视化.设置单个维度分数("谈话流利性", 42);
```

### 运行时添加维度
```csharp
// 清空现有维度
量表表格可视化.清空维度();

// 动态添加维度
量表表格可视化.添加维度("新维度", 容器Transform, 分数);

// 刷新显示
量表表格可视化.刷新显示();
```

## 调试信息

组件会输出以下调试日志：

1. **显示分数点**: `[量表表格可视化] 谈话流利性: 36分 -> 显示第7个点 (30分点)`
2. **绘制曲线**: `[量表表格可视化] 绘制曲线完成，点数: 120`
3. **更新完成**: `[打印报告] 量表表格可视化已更新，共30个维度`

## 注意事项

1. **分数点容器结构**: 确保每个容器下的子物体按照从高到低（100→0）排列
2. **维度名称匹配**: 维度名称必须与代码中的字典键完全一致
3. **LineRenderer 材质**: 如果曲线不显示，检查 LineRenderer 是否有正确的材质
4. **层级顺序**: 调整 LineRenderer 的 Sorting Order 确保曲线显示在最上层
5. **世界坐标**: 曲线使用世界坐标系，确保所有点的位置在同一坐标空间

## 优化建议

1. **性能优化**: 如果维度很多，可以降低平滑度参数
2. **视觉效果**: 可以调整曲线颜色和宽度以匹配UI风格
3. **动画效果**: 可以扩展组件添加点的淡入淡出动画
4. **交互功能**: 可以添加点击显示详细分数的功能

## 调试步骤

### 1. 使用调试助手
在量表表格界面上添加 `量表表格调试助手_茉` 组件：
- 关联 `可视化组件` 字段
- 关联 `测试点容器` 字段（如流利性容器）
- 启用 `显示Gizmos`

### 2. Scene视图调试
在Scene视图中可以看到：
- 绿色球体标记点的位置
- 红/绿/蓝坐标轴显示方向

### 3. 右键菜单调试功能
在Inspector中右键点击组件，选择：
- **打印所有点的坐标**: 查看所有点的世界坐标、本地坐标
- **测试曲线绘制**: 使用测试数据绘制曲线
- **强制刷新可视化**: 手动触发刷新
- **检查LineRenderer状态**: 查看曲线渲染器的详细状态

### 4. 常见问题排查

**问题1: 曲线不显示**
- 检查Console日志，查看点的坐标值
- 确认点的坐标不是(0,0,0)
- 检查LineRenderer的Width是否足够大
- 确认材质和Shader正确

**问题2: 坐标都是(0,0,0)**
- 确认UI已经完成布局（延迟2帧刷新）
- 检查分数点容器是否正确设置
- 确认维度名称匹配

**问题3: 曲线在错误位置**
- 尝试切换 `使用本地坐标` 选项
- 调整LineRenderer的Z坐标
- 检查Camera设置

**问题4: Nova UI坐标问题**
- Nova UI使用特殊的布局系统
- 确保在UI布局完成后再获取坐标
- 使用 `延迟刷新显示()` 协程等待布局

### 5. 调试日志关键字
搜索Console中的以下日志：
- `[量表表格可视化]` - 主要逻辑日志
- `[坐标转换]` - 坐标获取日志
- `[调试助手]` - 调试工具日志

## 坐标系统说明

### Nova UI 坐标特点
- Nova使用自己的布局引擎
- 坐标可能在布局后才确定
- 需要等待至少2帧才能获取正确坐标

### LineRenderer 坐标模式
1. **World Space** (`useWorldSpace = true`)
   - 使用世界坐标系
   - 适合3D场景中的UI
   
2. **Local Space** (`useWorldSpace = false`)
   - 使用本地坐标系
   - 适合Canvas内的UI元素

### 建议配置
对于Nova UI：
- 先尝试 `使用本地坐标 = false`（世界坐标）
- 如果不行，尝试 `使用本地坐标 = true`
- 调整 `曲线宽度` 到合适大小（建议10-50）
