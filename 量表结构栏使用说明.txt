==================================================
  量表结构栏使用说明
==================================================

一、功能概述
------------
量表结构栏_茉 继承自 量表评估基类_茉，用于评估结构与空间能力。

【2个评估维度】
1. 照画图 - 选项组性评估
2. 摆方块 - 选项组性评估

【特点】
- 简单明了，只有2个维度
- 都使用选项组性_茉组件
- 通过栏目组统一管理


二、数据结构
------------

【结构与空间记录类】(档案录.cs)

```csharp
public class 结构与空间记录 : 档案记录接口
{
    public string 评估时间 { get; set; }
    public 评估状态 是否完成 { get; set; }
    
    // 两个维度的分数
    public int 照画图总分;
    public int 摆方块总分;
    
    // 存储选项组名称和选中索引的映射
    public Dictionary<string, int> 选项组选择;
}
```

四、工作流程
------------

【评估流程】

1. 用户进入结构与空间评估界面
2. 系统自动还原之前保存的数据（如果有）
3. 用户完成"照画图"选项组评估
4. 用户完成"摆方块"选项组评估
5. 点击"提交"按钮
6. 系统检查两个维度是否都已完成
7. 保存数据并返回

【数据保存】

保存时会记录：
- 照画图的总分
- 摆方块的总分
- 所有选项组的详细选择（用于还原）
- 评估时间和完成状态

【数据还原】

重新打开界面时：
- 自动还原两个维度的选项组选择
- 显示在对应的UI组件上


五、完成条件检查
----------------

【检查逻辑】

提交时会检查：
- 所有栏目组（选项组性）是否全部完成
- 每个栏目组内的所有选项组都必须选择

【提示信息】

- 未完成时："请完成全部结构与空间评估后保存"

七、代码说明
------------

【核心方法】

1. 获取记录字段名称()
   - 返回："结构与空间记录"
   - 用于从档案中获取对应的记录对象

2. 检查是否全部完成()
   - 检查所有栏目组是否全部已选择
   - 返回 true/false

3. 获取未完成提示信息()
   - 返回提示文本
   - 显示给用户

4. 保存额外数据(object 记录)
   - 遍历所有栏目组
   - 根据维度名称保存对应的总分

九、常见问题
------------

Q1: 为什么只有2个维度？
A: 结构与空间评估只需要评估照画图和摆方块两个方面。

Q2: 可以添加更多维度吗？
A: 可以，在结构与空间记录类中添加字段，在保存额外数据方法中添加case分支即可。

Q3: 照画图和摆方块的评分标准是什么？
A: 由选项组中的选项索引决定，索引值即为分数。

Q4: 栏目组的维度名称必须完全一致吗？
A: 是的，switch语句是精确匹配的，必须使用"照画图"和"摆方块"。

Q5: 如果只完成一个维度可以保存吗？
A: 可以点击"返回"按钮保存为"未完成"状态，但不能点"提交"。

Q6: 选项组性如何配置？
A: 参考"栏目组配置说明.txt"和选项组性_茉的使用说明。

十一、与其他量表栏的对比
------------------------

【量表谈话栏】
- 维度较多，使用选项组性
- 有特殊的谈话内容输入

【量表命名栏】
- 5个维度，混合使用选项组性和输入框
- 复杂度较高

【量表阅读栏】
- 7个维度，都使用表分择性
- 维度最多

【量表书写栏】
- 6个维度，5个表分择性 + 1个直接输入
- 有特殊的输入处理

【量表结构栏】⭐当前
- 2个维度，都使用选项组性
- 最简单，配置最容易
- 适合初学者参考
