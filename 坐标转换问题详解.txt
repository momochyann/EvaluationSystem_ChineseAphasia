# 坐标转换问题详解

## 问题根源

### 场景结构
```
量表表格界面
  ├─ 流利性容器
  │   ├─ 100分点 (localPosition: -0.83, -329.56, 0)
  │   ├─ 90分点
  │   └─ 0分点
  ├─ 信息量容器
  │   ├─ 100分点 (localPosition: -0.83, -329.56, 0)  ← 和上面一样！
  │   ├─ 90分点
  │   └─ 0分点
  └─ 系列语言容器
      ├─ 100分点 (localPosition: -0.83, -329.56, 0)  ← 也一样！
      └─ ...
```

### 为什么所有点的本地坐标相同？

因为 `transform.localPosition` 是**相对于父物体**的位置：

```
流利性容器的0分点.localPosition = (-0.83, -329.56, 0)  ← 相对于流利性容器
信息量容器的0分点.localPosition = (-0.83, -329.56, 0)  ← 相对于信息量容器
```

虽然这两个点在**世界坐标**中位置不同，但它们在**各自父容器的本地坐标系**中位置相同！

## 解决方案

### 核心思路
将所有点的坐标转换到**同一个参考坐标系**（曲线容器的本地坐标系）

### 使用 InverseTransformPoint

```csharp
// ❌ 错误做法：直接使用localPosition
Vector3 坐标 = 点.localPosition;  // 相对于各自的父容器

// ✅ 正确做法：转换到同一参考系
Transform 曲线容器 = Nova曲线绘制器.transform;
Vector3 坐标 = 曲线容器.InverseTransformPoint(点.position);  // 相对于曲线容器
```

### InverseTransformPoint 原理

```
世界坐标 → 本地坐标

点A世界坐标: (500, 300, 0)
点B世界坐标: (600, 400, 0)
曲线容器世界坐标: (400, 200, 0)

转换后（相对于曲线容器）:
点A: (100, 100, 0)  ← 500-400, 300-200
点B: (200, 200, 0)  ← 600-400, 400-200

现在点的坐标不同了！✅
```

## 图解说明

### 错误的方式

```
[流利性容器]           [信息量容器]
世界:(100,200)         世界:(200,200)
    │                      │
    ├─ 0分点               ├─ 0分点
    │  本地:(-0.83,-329)   │  本地:(-0.83,-329)  ← 相同！
    
直接使用localPosition:
点1: (-0.83, -329)
点2: (-0.83, -329)  ← 所有点都一样！❌
```

### 正确的方式

```
[曲线容器] 世界:(0,0)
    │
    │ InverseTransformPoint转换
    │
    ├─ 流利性的0分点
    │  世界:(100,200) → 相对曲线容器:(100,200) ✅
    │
    └─ 信息量的0分点
       世界:(200,200) → 相对曲线容器:(200,200) ✅
       
转换后的坐标:
点1: (100, 200)
点2: (200, 200)  ← 不同了！✅
```

## 代码对比

### ❌ 错误代码
```csharp
Vector3 获取坐标(Transform 点)
{
    return 点.localPosition;  // 相对于各自父物体
}

结果：所有点都是 (-0.83, -329.56, 0)
```

### ✅ 正确代码
```csharp
Vector3 获取坐标(Transform 点)
{
    Transform 参考物体 = 曲线容器.transform;
    return 参考物体.InverseTransformPoint(点.position);  // 统一转换到曲线容器坐标系
}

结果：每个点都有不同的坐标
```

## Unity Transform 坐标转换方法

### 常用方法对照

```csharp
// 1. TransformPoint: 本地坐标 → 世界坐标
Vector3 世界 = 父物体.TransformPoint(本地坐标);

// 2. InverseTransformPoint: 世界坐标 → 本地坐标
Vector3 本地 = 父物体.InverseTransformPoint(世界坐标);

// 3. TransformDirection: 本地方向 → 世界方向
Vector3 世界方向 = 父物体.TransformDirection(本地方向);

// 4. InverseTransformDirection: 世界方向 → 本地方向
Vector3 本地方向 = 父物体.InverseTransformDirection(世界方向);
```

### 本次使用的方法

```csharp
// 将点的世界坐标转换为相对于曲线容器的本地坐标
Vector3 相对位置 = 曲线容器.InverseTransformPoint(点.position);
```

## 为什么要这样做？

### 原因1: 统一参考系
曲线的所有点必须在**同一个坐标系**中才能正确连接。

### 原因2: Nova UI 特性
Nova UI 的布局系统会将不同的UI块放在不同的容器中，但它们的本地坐标可能相同。

### 原因3: UIBlock2D 绘制需求
UIBlock2D 线段使用的 `localPosition` 是相对于其父物体（曲线容器）的，所以所有点的坐标也必须相对于曲线容器。

## 总结

### 关键点
1. ❌ 不要直接使用 `transform.localPosition`（相对于各自父物体）
2. ✅ 使用 `InverseTransformPoint(transform.position)`（转换到统一参考系）
3. 🎯 参考系选择：曲线容器的transform

### 核心代码
```csharp
Transform 曲线容器 = Nova曲线绘制器.transform;
Vector3 统一坐标 = 曲线容器.InverseTransformPoint(点.position);
```

这样就能确保所有点在同一个坐标系中，曲线才能正确绘制！
