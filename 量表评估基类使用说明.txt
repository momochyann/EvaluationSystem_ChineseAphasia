================================
量表评估基类使用说明
================================

📚 概述
-----------
`量表评估基类_茉` 封装了所有量表评估界面的通用逻辑：
✅ 数据保存与还原
✅ 按钮事件处理（提交、返回、取消）
✅ 初始化与生命周期管理
✅ 选项组/栏目组的统一管理

使用此基类，你只需要实现 3 个抽象方法，就能创建功能完整的量表评估界面！


🚀 快速开始 - 最简单的实现
-----------
public class 量表理解栏_茉 : 量表评估基类_茉
{
    // 1. 指定对应的档案记录字段名称
    protected override string 获取记录字段名称()
    {
        return "理解记录";
    }

    // 2. 检查是否所有必填项都已完成
    protected override bool 检查是否全部完成()
    {
        if (选项组性群 == null) return false;
        
        foreach (var 选项组 in 选项组性群)
        {
            if (选项组?.当前选中选项 == null)
                return false;
        }
        return true;
    }

    // 3. 提供未完成时的提示信息
    protected override string 获取未完成提示信息()
    {
        return "请完成全部理解评估后保存";
    }
}

就这样！你的量表评估界面已经完成了！🎉


📖 核心概念
-----------

1. 抽象方法（必须实现）：
   - 获取记录字段名称() - 返回档案中对应的记录字段名
   - 检查是否全部完成() - 检查所有必填项是否已完成
   - 获取未完成提示信息() - 返回未完成时的提示文本

2. 虚方法（可选重写）：
   - 初始化组件() - 查找选项组/栏目组等
   - 订阅事件() - 监听选择变化等事件
   - 取消订阅事件() - 取消事件订阅
   - 还原其他数据() - 还原输入框等其他UI
   - 保存额外数据() - 保存总分、输入框内容等
   - 清除所有选择() - 清除所有UI组件

3. 受保护的字段：
   - List<栏目组性_茉> 栏目组性群
   - List<选项组性_茉> 选项组性群
   - List<表分择性_茉> 表分择性群
   - Button 提交按钮/取消按钮/返回按钮

🎯 最佳实践
-----------

1. 记录字段命名规范
   档案中的记录字段名必须与 获取记录字段名称() 返回的字符串完全一致
   
   ✅ 正确：
   protected override string 获取记录字段名称() => "谈话记录";
   // 对应 档案.谈话记录
   
   ❌ 错误：
   protected override string 获取记录字段名称() => "谈话";
   // 找不到 档案.谈话

2. 记录类必须有这些字段：
   - public 评估状态 是否完成 { get; set; }
   - public string 评估时间 { get; set; }
   - public Dictionary<string, int> 选项组选择 = new Dictionary<string, int>();

3. 选择初始化方式：
   
   方式 A：选项组方式（默认，适合简单量表）
   protected override void 初始化组件()
   {
       base.初始化组件(); // 自动查找所有选项组
   }
   
   方式 B：栏目组方式（适合多维度量表）
   protected override void 初始化组件()
   {
       栏目组性群 = GetComponentsInChildren<栏目组性_茉>().ToList();
   }

4. 事件订阅模式：
   protected override void 订阅事件()
   {
       选项组性_茉.选择变化事件 += 你的处理方法;
   }

   protected override void 取消订阅事件()
   {
       // ⚠️ 必须取消订阅，避免内存泄漏
       选项组性_茉.选择变化事件 -= 你的处理方法;
   }

❓ FAQ
-----------
Q: 我的量表需要特殊的UI组件怎么办？
A: 在子类中声明字段，通过 还原其他数据() 和 保存额外数据() 处理。

Q: 基类会自动处理所有按钮吗？
A: 是的！只要在 Inspector 中配置好按钮引用即可。

Q: 我可以混用选项组和栏目组吗？
A: 不推荐。选择一种方式并坚持使用。

Q: 如何调试？
A: 基类已经包含详细的日志输出，查看 Console 即可。
